Get Lotus Assistant

Install Lotus Assistant on a supported device for convenient access. Installation availability depends on your browser and device.

Open Lotus Assistant
Having trouble installing?
  1. Make sure you are using the official Lotus Assistant website over HTTPS.
  2. If the install button says the app is already installed, look for Lotus Assistant in your apps or home screen.
  3. On a supported browser, use its menu and look for an option such as Install app or Add to Home Screen. The wording varies by device.
  4. If no installation option appears, your browser may not support installation from this page, or the site's PWA setup may need attention.
